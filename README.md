# 🎵 Terminal Lyrics Player

A Python project that displays synchronized lyrics in the terminal with a typewriter animation.

## Features

- ⏱ Timestamp-based lyric synchronization
- ⌨️ Typewriter animation
- 🎵 Compatible with LRC-style timestamps
- 🖥 Lightweight terminal interface

## Technologies

- Python
- sys
- time

## Run

```bash
python kalyani.py
```
